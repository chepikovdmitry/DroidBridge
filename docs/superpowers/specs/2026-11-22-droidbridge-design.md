# DroidBridge для macOS

DroidBridge — приложение для копирования файлов между Mac и Android по USB. Пользователь подключает разблокированный телефон, включает на нём «Передача файлов», открывает нужную папку и копирует файлы в обе стороны. Собственная кодовая база позволит исправлять ошибки и развивать приложение независимо от OpenMTP.

## Выбор подхода

- **Собственное приложение с MTP по USB.** Выбранный подход. Сценарий работает без USB-отладки и приложения на телефоне. Предлагаемый стек для первой версии — Swift, SwiftUI и сменный адаптер `libmtp`.
- **Форк OpenMTP.** Ускорил бы старт за счёт готовых функций, но перенёс бы существующие архитектурные решения и ошибки в DroidBridge.
- **Собственное приложение через ADB.** Позволило бы быстро проверить передачу файлов в сценарии для разработчиков. Пользователю пришлось бы включить USB-отладку и авторизовать Mac на телефоне.

## Первая версия

Одновременно подключён один телефон. Пользователь видит папки Mac и телефона, выбирает доступное хранилище телефона, копирует файлы и папки кнопкой или перетаскиванием. Очередь показывает текущий файл, прогресс, завершённые и неудавшиеся операции. Ожидающие задания можно отменить. Для текущего файла интерфейс показывает, когда отмена запрошена и когда она завершена. Поддержку прерывания текущего файла определит проверка на устройствах.

При совпадении имён приложение предлагает пропустить файл или сохранить его под другим именем. Удаление и перезапись файлов телефона, синхронизация и передача по Wi‑Fi остаются за рамками первой версии.

## Архитектура

- SwiftUI отображает папки, очередь и состояние подключения. macOS 26 на Apple Silicon — первая среда для проверки. Минимальную поддерживаемую версию macOS определим перед выпуском.
- Модуль передачи на Swift отвечает за очередь, выбор имени при конфликте и состояния операций. Локальные файлы обрабатываются через Foundation. Контракт доступа к телефону использует идентификаторы хранилищ и объектов MTP вместо локальных путей.
- Адаптер `libmtp` владеет соединением и выделенной очередью для блокирующих вызовов. У телефона одна активная операция. После переподключения приложение создаёт новую сессию и заново читает содержимое папки. Адаптер можно заменить без переделки интерфейса и очереди.
- Скачивание пишет во временный файл рядом с назначением. При успешном завершении и проверке размера этот файл получает итоговое имя без перезаписи существующего. При обрыве локальная временная копия удаляется. Для загрузки на телефон при обрыве состояние результата может быть неизвестно. После переподключения приложение обновляет папку и показывает результат пользователю перед повторной попыткой.
- Тестовая реализация доступа к телефону позволяет воспроизводить отключение, конфликт имён и ошибки передачи без подключённого устройства.

## Проверка USB до разработки интерфейса

На реальном Android-телефоне проверить обнаружение в режиме «Передача файлов», чтение `Download` и копирование файла в обе стороны со сверкой SHA-256 после обратного копирования. Повторить с именем на кириллице и файлом больше 4 ГБ при наличии места. Отдельно проверить отмену и отключение кабеля в обоих направлениях. Зафиксировать, в каком состоянии остаётся устройство, виден ли частичный файл и удаётся ли повторить копирование после нового подключения.

`libmtp` — кандидат для проверки. Поведение отмены зависит от устройства. Перед выпуском проверить условия распространения библиотеки и добавить в матрицу совместимости модели, на которых выполнены проверки.
