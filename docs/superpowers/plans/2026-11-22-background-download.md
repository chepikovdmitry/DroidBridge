# Скачивание независимо от обновлений окна

Держать весь непрерывный участок пачки на существующей последовательной USB-очереди. Отправлять снимки прогресса и результаты в UI по мере необходимости. Останавливаться перед конфликтом, который требует решения пользователя. Использовать независимый флаг отмены для каждого файла. Проверить очередь без устройства, собрать новую версию без остановки текущей передачи.
