# Security policy

## Supported versions

Report issues that affect the latest published [DroidBridge release](https://github.com/chepikaudzmitry/DroidBridge/releases) or the current `master` branch. Include the exact version or commit you tested.

## Reporting a vulnerability

Use [Report a vulnerability](https://github.com/chepikaudzmitry/DroidBridge/security/advisories/new) when GitHub private reporting is available. While the repository is private, contact the maintainer privately through the channel used to arrange repository access.

Include the affected version, prerequisites, steps to reproduce and potential impact. Use test files and remove credentials, device identifiers and personal data from attachments. Keep vulnerability details out of Issues and pull requests.

For ordinary bugs, use the [bug report form](https://github.com/chepikaudzmitry/DroidBridge/issues/new?template=bug-report.yml).
