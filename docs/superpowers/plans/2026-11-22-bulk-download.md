# Ускорение пакетного скачивания

- Один список идентификаторов MTP и один индекс имён назначения на пачку. Проверять метаданные конкретного объекта перед чтением и сохранять эксклюзивную запись результата.
- Обновлять локальную панель в конце непрерывной пачки. Переиспользовать сортировку, когда меняется только состояние очереди.
- Дать возможность пропустить все совпадения в пачке при повторном запуске. Собирать новую версию без перезапуска текущего копирования.
